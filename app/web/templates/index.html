Ledger to Companies House

Record transactions, prepare micro-entity, small or dormant accounts as iXBRL, check them with Arelle, and file with Companies House.

Before you file anything real

  1. Set up a company and its chart of accounts.
  2. Record journal entries for the accounting period.
  3. Enter the accounts details directors must confirm (approval date, employees, principal activities).
  4. Generate the iXBRL accounts and check the reconciliation against the ledger.
  5. Validate the file with Arelle.
  6. File with Companies House in test mode first, then live only once you trust the result.
